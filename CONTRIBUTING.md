# Contributing

Thanks for helping with Orbite!

- **Bugs and ideas**: open an [issue](https://github.com/MatisMLDR/Orbite/issues). For a bug, say what you did, what you expected and what happened, with your macOS version.
- **Code**: see [Build from source](README.md#build-from-source). Keep pull requests focused on one change, run the tests (`xcodebuild test -project Orbite.xcodeproj -scheme Orbite`) and describe how you checked the change.
- **Translations**: the interface text is in English in the code and translated in `Orbite/Localizable.xcstrings`, `OrbiteWidget/Localizable.xcstrings`, `Orbite/InfoPlist.xcstrings` and `Orbite/AppShortcuts.xcstrings`. Open them in Xcode to add a language.
- **Security issues**: please follow [SECURITY.md](SECURITY.md) instead of opening an issue.
